# Zarvel Customer Portal

WordPress plugin for the Zarvel customer portal.

Current features:

- Gmail-only one-time-code portal sign-in.
- Frontend portal shortcode: `[zarvel_customer_portal]`.
- Zarvel Customers admin menu.
- Private custom product access by verified portal email.
- Design request lookup by customer email.
- WooCommerce order count and total spent by verified checkout email.

The plugin folder can be installed in `wp-content/plugins/zarvel-customer-portal`.
